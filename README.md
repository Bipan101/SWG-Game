# 🐍 Snake Water Gun Game
A simple command-line implementation of the classic Snake, Water, Gun game (a variation of Rock, Paper, Scissors) built using basic Python.<br>
This beginner-friendly game is perfect for learning how to use conditionals, loops, and user input in Python.

## 🎮 How to Play
The game is played between the user and the computer.

The three choices are:

Snake

Water

Gun

## Game Rules:

Snake drinks Water → Snake wins 🐍💧

Water douses Gun → Water wins 💧🔫

Gun kills Snake → Gun wins 🔫🐍

If both players choose the same, it's a tie.

## 🛠 Features
Interactive CLI-based gameplay.

Randomized computer choices using Python’s random module.

Score tracking for user vs. computer.

Clean and simple logic using basic conditionals (if/elif/else).

## 🚀 Getting Started
Prerequisites
Python 3.x installed on your system.

## How to Run
Clone or download the repository.

Open a terminal/command prompt in the project directory.

## Run the script using:

```
python SWG.py
```
```
Enter your choice (s/w/g): s
Computer chose: water
You win this round!
```

Score: You - 1 | Computer - 0
